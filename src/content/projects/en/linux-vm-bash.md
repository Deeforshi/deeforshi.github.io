## Context

Systems administration project covering **Linux virtual machine provisioning** and automated multi-user governance via **Bash scripting**.

## System Engineering

- **VM provisioning**: configured VirtualBox networking, OS installation, partitioning, and essential system services.
- **Bash automation**: authored repeatable scripts to create users, assign groups, and scaffold shared workspace trees.
- **Access control**: enforced Unix permissions (`chmod`, `chown`, umask) and verified cross-user isolation.

## Key Takeaway

Practical command of **Linux CLI** and shell automation — a core prerequisite for Docker, CI/CD pipelines, and server operations.
