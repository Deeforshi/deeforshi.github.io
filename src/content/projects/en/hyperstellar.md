## Context

**Hyperstellar** is a turn-based 2D strategy board game implemented in **C#**, built to apply object-oriented design principles alongside **UML** modeling.

## Design & Mechanics

- **UML Modeling**: created class and sequence diagrams upfront to keep core game rules decoupled from rendering.
- **Board Rotation**: implemented matrix rotation mechanics forcing players to plan around shifting spatial states.
- **Rule Enforcement**: strict move validation, alternating turn state machine, and automated victory detection.

## Key Takeaway

Strengthened my command of **C# OOP**, 2D grid algorithms, and clean separation between game logic and UI.
