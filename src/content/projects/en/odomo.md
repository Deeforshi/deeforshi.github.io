## Context

**Odomo** is a Java project focused on reliable environmental data processing (home weather station and garden management) paired with disciplined **automated unit testing**.

## Engineering & Testing

- **Weather analytics**: daily and monthly aggregations, precipitation tracking, and threshold checks.
- **Garden module**: zone management, watering calculations, and structured console reporting.
- **JUnit & Hamcrest**: expressive test assertions verifying both nominal scenarios and edge cases (boundary values, empty datasets).

## Key Takeaway

Built strong engineering habits around **unit testing**, data validation, and clean Java modularization.
