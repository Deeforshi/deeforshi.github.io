## Context

As part of my Computer Science degree, our team built a **TV series browsing and tracking web app** with **Symfony**.

## Architecture & Features

- **Doctrine ORM modeling**: structured relational schema covering shows, seasons, episodes, genres, ratings, and users.
- **Security & Roles**: registration, login, role-based permissions (`ROLE_USER`, `ROLE_ADMIN`), and catalog administration.
- **Twig templating**: dynamic server-rendered views, multi-criteria filtering, and validated Symfony forms.
- **Scrum delivery**: backlog refinement, sprint reviews, and coordinated Git workflows across teammates.

## Outcome

A working MVC web application built with Symfony, featuring a clean relational schema, role-based access control, and team Git workflows.
